## Продукти навколо робочих процесів

Створюємо пов’язані рішення для торгових команд, постачальників і бізнес-клієнтів. Поєднуємо щоденну роботу у зрозумілі процеси, пов’язуючи веб і мобільні застосунки із зовнішніми бізнес-системами.

## Пов’язана екосистема

**Torg** організовує роботу команди. **Torg Mobile** фіксує роботу в торговій точці. **B2B Portal** дає клієнтам можливість підготувати й передати замовлення. Визначені контракти інтеграції поєднують ці процеси із зовнішньою системою, де залишається товарний і бухгалтерський облік.

## Інженерна основа

- React, Next.js і React Native для вебу та мобільних пристроїв.
- Python, FastAPI і PostgreSQL для сервісів застосунків.
- Визначені API, версіоновані міграції та окремі межі застосунків.
- Автоматичні перевірки й повторюване розгортання в Docker.
