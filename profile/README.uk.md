### Рішення для щоденної роботи

Створюємо пов’язані програмні продукти для торгових команд, постачальників і бізнес-клієнтів. Зосереджуємося на зрозумілих процесах, надійній взаємодії систем та зручній роботі з комп’ютера і телефона.

| Бізнес-платформи | Цифрова комерція | Мобільна робота |
| --- | --- | --- |
| Команди, маршрути, візити та оперативна звітність. | B2B-каталоги, замовлення, звернення та інформація про доставку. | Робота в торгових точках, фото, координати та синхронізація. |

### Пов’язана екосистема

**Torg** — робочий простір для управління торговими командами, точками та польовою роботою. Взаємодіє із зовнішніми обліковими системами через визначені API.

**B2B Портал** — прямий канал між постачальником і бізнес-клієнтом: асортимент, замовлення та обслуговування в одному інтерфейсі, пов’язаному з Torg.

**Мобільний застосунок** — інструмент торгового представника для візитів, замовлень і синхронізації під час роботи в полі.

### Основа для розвитку

- Окремі застосунки та визначені контракти інтеграції.
- React, Next.js і React Native для вебу та мобільних пристроїв.
- Python, FastAPI, PostgreSQL і версіоновані міграції.
- Автоматичні перевірки, розгортання в Docker і перевірені процедури відновлення.
